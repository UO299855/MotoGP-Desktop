Circuito

Esta sección permite al usuario visualizar archivos auxiliares que proporcionan información sobre el circuito Pertamina Mandalika, en Indonesia. Si el navegador lo soporta, pueden visualizarse:

  • Archivo HTML con información general del circuito, así como imágenes y vídeos del mismo
  • Archivo SVG con el perfil de altimetría del circuito
  • Archivo KML con la planimetría del circuito

Los archivos a cargar pueden encontrarse dentro de la carpeta "xml" del proyecto.

Juegos

Esta sección contiene enlaces a varias páginas relacionadas con el proyecto. Veamos qué contiene cada una de ellas.

Juego de memoria con cartas

Se muestra un tablero con doce cartas boca abajo. Hay seis parejas de cartas idénticas con temática de MotoGP

Cada vez que el usuario hace click en una carta, esta se volteará, mostrando la pareja a la que pertenece. No pueden revelarse más de dos cartas por jugada. Al mostrar la segunda, se dejará la pareja volteada por un tiempo para que el usuario memorice su posición.

En caso de acertar, ambas cartas permanecerán reveladas y no se podrá interactuar más con ellas. En caso contrario, se volverán a ocultar.

El juego cuenta con un cronómetro que se inicia cuando el usuario visita la página. Al terminar el juego, el cronómetro se detiene, mostrando al usuario su tiempo final.

Cronómetro en JavaScript

El siguiente juego es un cronómetro que se actualiza en tiempo real. El usuario puede arrancarlo, pararlo y reiniciarlo pulsando los botones correspondientes. El cronómetro irá mostrando el tiempo transcurrido actualizándose en tiempo real.

Cronómetro en PHP

Este cronómetro es distinto del anterior, pues no se muestran actualizaciones visuales del tiempo transcurrido continuamente. En cambio, este cronómetro seguirá llevando la cuenta incluso si el usuario cambia a otra página del sitio y regresa después. Para ver el tiempo transcurrido, se ha de pulsar en "parar" y posteriormente en "mostrar".
